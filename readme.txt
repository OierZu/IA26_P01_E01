How to run
  1. Install: pip install pandas numpy matplotlib jupyter
  2. Open a terminal in the notebooks/ folder: jupyter notebook 01_Project01_E01.ipynb
  3. Run all cells (about 40 seconds). The notebooks load the data with relative paths (../data_tiny).
  Only pandas, numpy, matplotlib, heapq, time and itertools are used.
